# ApexPlanet Task 3 – Customer Segmentation Analysis
## Project Overview
This project analyzes e-commerce sales data and segments customers based on their total sales value. The goal is to understand customer purchasing patterns and identify useful business insights.
## Objectives
- Analyze customer-level sales performance.
- Segment customers into High Value, Medium Value, and Low Value groups.
- Calculate key performance indicators (KPIs).
- Visualize customer segments and sales patterns using Power BI.
## Tools Used
- Python
- Pandas
- Jupyter Notebook
- Microsoft Power BI
- Excel
## Customer Segmentation
Customers are grouped based on their total sales:
- **High Value:** Total sales of ₹200,000 or more
- **Medium Value:** Total sales from ₹75,000 to below ₹200,000
- **Low Value:** Total sales below ₹75,000
## Key Results
- Total sales: approximately ₹139.40 million
- Total orders: 992
- Total quantity sold: 5,435
- Unique customers: 947
- High Value customers: 264
- Medium Value customers: 356
- Low Value customers: 327
## Dashboard
The Power BI dashboard presents sales KPIs, customer segment distribution, and sales analysis by category and city for High Value customers.
## Conclusion
Customer segmentation helps identify groups with different sales contributions and supports better-targeted marketing and customer retention strategies.
